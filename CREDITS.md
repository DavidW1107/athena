# Credits

## Application icon

The Corinthian helmet mark is **"Spartan helmet" by Delapouite**, from
[game-icons.net](https://game-icons.net/1x1/delapouite/spartan-helmet.html), used under the
[Creative Commons Attribution 3.0 Unported licence](https://creativecommons.org/licenses/by/3.0/).

Changes made: recoloured to the application ink `#f2f2f2` and composited onto a rounded
`#1e1e1e` ground to produce `src-tauri/icons/*`. The unmodified source is kept at
`assets/athena-mark.svg`.

CC BY 3.0 requires this attribution to travel with the work, which is why this file exists and
why the README points at it. If the icon is ever replaced, remove this section with it.

## Terminal palette

The sixteen ANSI colours in `src/term.js` and the surface tokens in `src/style.css` come from the
"VS Code" palette shipped with [Ptyxis](https://gitlab.gnome.org/chergert/ptyxis), which in turn
credits [Gogh](https://github.com/Gogh-Co/Gogh) (`Vs Code Dark+.yml`). Colour values are facts
about a theme rather than creative work, but the provenance is recorded here so the source of the
palette is not lost.
